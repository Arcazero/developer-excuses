One funny single-line excuse a developer gives when code breaks in production, under 200 characters. The program writes the line to `/output/entry.txt`, where a house judge compares it head to head against other entries in private blind rounds — the line that lands the biggest laugh most often takes first place.

The excuse: "The bug isn't new — production just ran the code path I swore was unreachable."

## Run it

```sh
python3 main.py
```
